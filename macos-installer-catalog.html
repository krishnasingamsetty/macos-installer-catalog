Advanced settings (catalog URL, CORS proxy)
Apple doesn't allow cross-origin browser requests to its catalog server, so this tool routes through a public CORS proxy. If fetching fails, try swapping the proxy for another (e.g. https://corsproxy.io/?url=), or self-host a tiny one (a one-file Cloudflare Worker or Vercel Edge Function that fetches the URL and adds Access-Control-Allow-Origin: * works well and is more reliable than public proxies for a project you publish widely).
